# A-Nomad Comments

This repository stores public comments and discussions for articles published on
a-nomad.com.

## Purpose

- Discuss public articles published on a-nomad.com
- Ask questions related to the article content
- Share corrections, experiences, and additional references

## Public visibility

Discussions in this repository are public. Do not post:

- Passwords
- Email addresses or phone numbers
- Order or payment information
- Private account information
- Sensitive personal information
- Private feedback that should not be publicly visible

## Moderation

The site owner may hide, delete, lock, or otherwise moderate discussions and
comments that are abusive, irrelevant, promotional, illegal, or sensitive.

## Private contact

For account issues, private feedback, copyright concerns, or sensitive matters,
please use the private contact channel provided on a-nomad.com instead of
posting publicly here.

## Technical note

This repository is used by Giscus and GitHub Discussions. It does not contain
the Website source code or private knowledge-base content.
